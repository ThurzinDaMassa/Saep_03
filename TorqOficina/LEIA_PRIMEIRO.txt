TORQ OFICINA - GRUPO 04

1. Leia README.md para configurar e executar o sistema Java + MySQL.
2. Configure os dados de conexão em config.properties.
3. Inicie seu servidor MySQL e execute preparar_banco.bat.
4. Execute iniciar.bat e abra http://localhost:8080.

No IntelliJ: abra pom.xml e use as configurações da pasta .run.
Primeiro execute "Torq Oficina - Preparar banco"; depois "Torq Oficina - Iniciar".
O Java usa config.local.properties quando presente; o ZIP usa config.properties.
Confira no console a porta do endereço HTTP. Instruções completas em README.md.
